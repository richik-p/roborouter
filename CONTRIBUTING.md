# Contributing

RoboRouter is pre-beta. Keep changes scoped to a milestone in
`docs/issues/BACKLOG.md` and preserve the accepted decisions in
`docs/DECISIONS.md`.

1. Create a focused branch.
2. Add an ExecPlan when required by `PLANS.md`.
3. Update contracts, generated schemas, tests, and documentation together.
4. Run `make check`.
5. Explain user-visible behavior, evidence changes, and unresolved risks in the
   pull request.

Do not add uploaded-code execution, cloud physical-safety authority, silent
policy fallback, billing, or a new universal robot protocol to MVP work.
