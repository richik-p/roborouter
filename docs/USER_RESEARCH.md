# User research hypotheses

**Reconstructed:** 2026-08-20. No prior interview notes were present, so this
file records hypotheses rather than invented findings.

## Hypotheses to test

1. Developers lose meaningful time translating policy assumptions into their
   robot's cameras, state, control surface, normalization, and runtime.
2. Evidence-qualified incompatibility is useful even when RoboRouter cannot run
   a model.
3. A simulator-first comparison workflow attracts users without hardware.
4. Rollout provenance and traces make trying a second model materially easier.
5. A robot owner will install a read-only agent when it does not replace their
   middleware or safety stack.
